# Optional assets to upload

The game works with zero uploads: icons are emoji, models are built from parts, and sounds use files built into Roblox. Uploading these makes it feel even more premium. After uploading, paste each `rbxassetid://…` into `ReplicatedStorage › Shared › Config › Assets`.

## Icons (`Assets.Images`)
Make them 512×512 PNGs with transparent backgrounds. Prompt for any image generator:

> *glossy 3D cartoon game icon of a ___, chunky shapes, thick dark purple outline, vibrant saturated colors, soft highlight, transparent background, Roblox simulator style*

| Key | Subject |
|---|---|
| Shop | shopping bag with a star |
| Pets | cute paw print / pet egg |
| Devices | retro camera |
| Rebirth | two circular arrows with sparkle |
| Upgrades | lightning bolt |
| Daily | calendar page |
| Gifts | red gift box |

| Clout | gold coin with a +1 |
| Tickets | blue ticket |

## Stud texture (`Assets.Images.StudTexture`)
A seamless **grayscale** tile of one round Lego-style stud (256×256). The game tints it per part, so one texture works for every colour. Until you upload one, the map uses Roblox's built-in stud surface.

## Sounds (`Assets.Sounds`)
The defaults are Roblox client sounds (click, ping, swoosh). Good replacements from the Creator Store are pop, coin, level-up, whoosh, drum roll, victory and boing.

## Music (`Assets.Music`)
One looping track per world: chill lo-fi (Park), synthwave (Neon City), cozy chiptune (Frosty Servers), epic space (Galaxy Studio).
